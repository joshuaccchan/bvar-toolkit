# bvar-toolkit

MATLAB code for large Bayesian VARs by [Joshua Chan](https://joshuachan.org), consolidating the
packages distributed at [joshuachan.org/code.html](https://joshuachan.org/code.html).

**Current state: verbatim archive (v0).** Each `replications/<paper>/legacy/` folder contains the
original code package exactly as published on the website, imported in one commit per package with
the zip's md5 hash and source URL recorded in the commit message and a permanent
`as-published/<paper>` tag. These folders are never edited.

A documented core library (`core/+bvt/`), worked examples, and tested per-paper replication
drivers will be added on top; see `provenance.md` for the import record.

If you use this code, please cite the paper listed in the corresponding import commit and in
`provenance.md`.
