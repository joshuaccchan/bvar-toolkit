This zip file contains matlab code for estimating two models:
the unobserved components  model with stochastic volatility
(UC.m) and the time-varying parameter vector autoregression
(TVPVAR.m). The m-files implement the precision-based sampler in
Chan and Jeliazkov (2009). 

This code is free to use. When you use the code in your research,
please cite:

Chan, J.C.C. and Jeliazkov, I. (2009). Efficient Simulation and
Integrated Likelihood Estimation in State Space Models,
International Journal of Mathematical Modelling and Numerical
Optimisation, 1, 101-120.
