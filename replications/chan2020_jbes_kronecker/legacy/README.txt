This zip file contains Matlab code for replicating the empirical applicaiton in Chan (2020).
The main file to replicate the full sample estimation results is:

main_BVAR.m 

The main file to replicate the real-time forecasting exercise is:

main_forecasting.m

This code is free to use for academic purposes only, provided that the 
paper is cited as:

Chan, J.C.C. (2020). Large Bayesian VARs: A flexible Kronecker error 
covariance structure, Journal of Business and Economic Statistics, 38(1), 68-79.

This code comes without technical support of any kind. It is expected to
reproduce the results reported in the paper. Under no circumstances will
the author be held responsible for any use (or misuse) of this code in any way.
